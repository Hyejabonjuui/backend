# 프로젝트 개요

## 한 줄 소개

**혜자**는 흩어져 있고 자격 조건이 복잡한 정부·지자체 청년 주거 정책을 사용자가 자신의 조건에 맞춰 찾도록 돕는 웹 서비스다. 팀명은 `혜자본주의`이며 LG CNS AM Inspire Camp 6기 미니 프로젝트로 시작했다.

## 해결하려는 문제

청년 주거 정책은 기관별로 흩어져 있고 용어와 신청 조건이 복잡하다. 혜자는 외부 정책 데이터를 서비스 DB에 저장하고, 사용자의 지역·나이·취업·소득·주거 조건 등을 바탕으로 필요한 정책을 탐색하고 필터링할 수 있게 하는 것을 목표로 한다. AI 기반 추천·요약은 이 목표와 구분되는 추후 개발 항목이다.

주요 사용자 조건은 다음과 같다.

- 생년월일과 거주 지역
- 취업 상태와 소득 구간
- 무주택 여부와 주거 형태
- 혼인 여부와 학력

## 현재 MVP 범위

현재 기준으로 포함할 제품 영역은 다음과 같다.

- 외부 청년 정책 데이터 동기화와 자체 DB 저장
- 주거 정책 목록·상세·검색·필터
- 회원 계정과 조건 프로필
- 관심 정책
- 카드뉴스
- 알림
- 정책 용어 풀이
- 웹 전용 반응형 UI를 지원하는 API

단, 위 목록에 있더라도 실제 구현 여부는 코드에서 확인한다. 현재 백엔드는 일부 조회·동기화 API만 구현된 상태다.

## 제외하거나 미룬 범위

| 항목 | 현재 결정 |
| --- | --- |
| 지도 | 이번 범위에서 제외 |
| 캘린더 | 이번 범위에서 제외 |
| 관리자 기능 | 이번 범위에서 제외 |
| AI 추천·요약 | 추후 개발 |
| 토큰 기반 인증 | 추후 개발 |
| 운영 배포 | 진행하지 않음 |
| 모바일·태블릿 전용 앱 | 진행하지 않음. 웹 반응형만 지원 |

초기 수행계획서에는 지도·캘린더·AI가 핵심 기능으로 적혀 있지만, 위의 최근 결정이 우선한다.

## 정보 우선순위

현재 구현을 확인할 때 서로 다른 자료가 충돌하면 다음 순서를 따른다.

1. 현재 브랜치의 실제 코드와 테스트
2. Figma 화면 설계
3. API 명세, ERD, 수행계획서와 기타 문서

현재 이슈의 명시적 요구사항은 목표 상태를 정하며 오래된 자료보다 우선한다. 다만 확정만 되고 코드에 아직 반영되지 않은 내용은 현재 동작처럼 서술하지 않고, `docs/domain-model.md`의 정합성 표처럼 별도로 표시한다.

## 현재 구현 스냅샷

2026-09-25 기준 실제 코드에 존재하는 주요 기능은 다음과 같다.

- 헬스체크
- 외부 정책 수동 동기화
- 저장된 정책 목록 조회
- 비회원용 카드뉴스 조회
- 임시 `memberId` 기반 회원 계정 조회
- 임시 `memberId` 기반 알림 목록 조회

Profile, Favorite, Region, Term의 HTTP API와 로그인·회원가입 등은 아직 구현되지 않았거나 명세 단계다. 구체적인 경로는 `docs/api-conventions.md`를 참고한다.

## 품질 기준

- 현재 Gradle 테스트는 H2 기반이다.
- 기존 테스트에는 엔티티 제약, enum converter, 일부 서비스·컨트롤러, 시드, 공통 예외 처리가 포함된다.
- 수행계획서의 “테스트 90%”는 코드 커버리지인지 테스트 케이스 통과율인지 아직 확정되지 않았다.
- JaCoCo 등 커버리지 측정 기준은 현재 설정되어 있지 않다.
